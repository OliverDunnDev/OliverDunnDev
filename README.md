### 🧠 Q-SafeML

**Python · Qiskit · Machine Learning · Quantum Computing**

My undergraduate research project investigating whether existing SafeML approaches could be adapted using quantum distance metrics to assess the safety and reliability of machine-learning models in quantum computing environments.

The project involved experimental work with Python, Qiskit, machine learning models, GANs, classification techniques, and statistical/quantum distance metrics.

The resulting dissertation was published on arXiv.
